Recent Projects

HTML Editor

How to use: নিচের diagram দেখে HTML structure বুঝে কোড লিখুন। যদি আপনি নতুন হন, আগে `<!DOCTYPE html>`, তারপর `<html>`, তারপর `<head>`, তারপর `<body>` লিখুন। `<head>`-এ title/meta/link/script থাকে, আর `<body>`-তে দেখা যায় এমন content থাকে।
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Your Page Title</title> <style>/* CSS here */</style> <script>/* JavaScript here */</script> </head> <body> <header>Top area</header> <main>Main content</main> <section>Any section</section> <footer>Bottom area</footer> </body> </html>
মনে রাখুন: যেকোনো web page বানাতে এই skeleton-টাই base হিসেবে কাজ করে; ভিতরের অংশ বদলালে আলাদা page, app, portfolio, form, blog, store—সবই তৈরি করা যায়।

Blockly

How to use: Blocks button চাপলে সব major category-এর shelf খুলবে। Logic, Loops, Math, Text, Lists, Colour, Variables, Functions এর block add করে শুধু blocks দিয়েই simple apps/logic তৈরি করা যাবে। Variables block-এ variable create/rename/delete করা যাবে, আর toolbox-এ আরও blocks রাখা হয়েছে যাতে code-based thinking ছাড়াও visual logic build করা যায়।

Tap any block to add it to the workspace.

App Guide

একটি website/app/page বানাতে প্রথমে boilerplate structure ব্যবহার করুন: DOCTYPE → html → head → body। head-এ metadata ও scripts, body-তে content থাকবে।

Heading, paragraph, button, image drag করে canvas-এ drop করুন। Generate HTML দিয়ে editor-এ পাঠান।
